name: Written response progression
description: Non-choice instructor decisions, automatic points, and revision rules for both activities.
---

Written responses require explicit instructor approval before the learner can proceed. A denial requires a meaningful revision and resubmission, not an unchanged or whitespace-only retry.

**Why:** The user requested “if the instructor approves the submission they can move on if they deny the submission the user must reattempt the question.”

**How to apply:** In SILENT LANTERN, gate navigation and final submission on approval, not merely on awarded points. Keep revisions pending until reviewed again, and tie review decisions to the response version so a stale decision cannot approve newer work.

Both activities now require the three instructor actions for **every effective non-choice response**, including typed flags: Accept response, Accept with feedback, or Deny with feedback. Acceptance awards the full question points automatically; pending and denied responses earn zero. Feedback is required for the two feedback actions, not for plain acceptance.

**Why:** The user explicitly expanded the review requirement to “any response that is not multiple choice” in both projects and requested automatic addition of accepted points.

**How to apply:** Distinguish the actual learner-facing input from its original authoring type: evidence questions that are rendered as choices remain self-verifying. Any accepted answer that is edited needs a new acceptance. Final completion requires all choices correct and all non-choices accepted.
